## Graphics

The lava-manufacturer (stone->lava melter) building + icon graphics are the
"glass-furnace" set, and the electrolysis-cell (signature aluminium building) +
icon graphics are the "oxidizer" set, all by **Hurricane**
(https://mods.factorio.com/user/Hurricane046), licensed **CC-BY**, originally
made for the "LL" mod (the oxidizer as bundled in the Nullius Visual Overhaul).
The "arc-furnace" set (also Hurricane046, CC-BY) dresses the iron-recovery
building (`cindra-arc-furnace`) from `graphics/entity/arc-furnace/`. That set
ships no frozen layer, so the arc furnace's frost patch
(`arc-furnace-hr-frozen.png`, ci-u92y) was DERIVED from Hurricane's body render
by `scripts/gen-frost-layer.py`. CC-BY permits adaptations with attribution, so
the derived layer carries the same credit and licence as the art it comes from.
