# Setup — what to add manually after cloning

The repo is self-contained for **source and bundled mod dependencies** (`mods/`,
`vendor/`, scripts, docs). A few things are **gitignored** (too large,
machine-specific, or regenerated) and must be provided locally after a fresh
clone.

## 1. Node dependencies (for the test runner)

`node` isn't assumed on PATH — wrap with nix:

```sh
nix shell nixpkgs#nodejs -c npm install
```

Installs `factorio-test-cli` into `node_modules/` (gitignored).

## 2. Factorio install (required)

The `factorio/` directory is gitignored (multi-GB binary + DLC data). Provide a
**Factorio 2.1.9 Space Age** install:

1. Obtain the Linux Space Age tarball
   (`factorio-space-age_linux_2.1.9.tar.xz`) from your factorio.com account.
2. Extract it so the tree lives at `./factorio/`:
   ```sh
   tar -xf factorio-space-age_linux_2.1.9.tar.xz -C .
   ```
3. **On NixOS**, patch the binary so graphics work:
   ```sh
   ./scripts/patchelf-factorio.sh
   ```
   Sets a concrete nix-store glibc ELF interpreter **and** the RUNPATH so SDL can
   find libX11 / libGL at runtime. **Required after every fresh extraction** — a
   stock tarball ships the FHS interpreter, which crashes SDL with the misleading
   "No available video device" even on a machine with a display.

Verify:

```sh
./factorio/bin/x64/factorio --version   # → Version: 2.1.9
```

## 3. factorio-test runner wiring

`vendor/factorio-test` is a committed source build of 3.1.1. The test runner
needs it visible under the data dir so it doesn't try to download it:

```sh
mkdir -p factorio-test-data-dir/mods
ln -sfn ../../vendor/factorio-test factorio-test-data-dir/mods/factorio-test_3.1.1
```

(The rest of `factorio-test-data-dir/` is regenerated by the CLI each run.)

## Then

Launch the game:

```sh
./play.sh
```

Run the test suite (`recycler` is a required built-in DLC in 2.1):

```sh
nix shell nixpkgs#nodejs -c ./node_modules/.bin/factorio-test run \
  --factorio-path ./factorio/bin/x64/factorio \
  --data-directory ./factorio-test-data-dir \
  --mod-path ./mods/cindra \
  --mods space-age quality elevated-rails recycler
```

To verify the Any-Planet-Start companion chain (`cindra-start` +
`cindra-dev-default`) loads clean both WITH and WITHOUT Any Planet Start, see the
"Companion mods" block in [`README.md`](README.md#companion-mods-any-planet-start-chain).
Any Planet Start is an optional dependency and is no longer vendored; the
with-APS suite needs a local checkout (from the mod portal) pointed at by
`APS_PATH`, while the without-APS suite needs no external mod.

## Regenerated automatically — do NOT add these manually

- `factorio-test-data-dir/` — created/refreshed by the test CLI each run (except
  the `factorio-test_3.1.1` symlink from step 3).
- `mods-bundle/` — created by `play.sh` each run.
- `node_modules/`, `package-lock.json` — from `npm install`.
